# components/

| Folder | What |
|---|---|
| `ui/` | Shared controls (Input, Select, AppCheckbox, Switch, Stepper, DatePicker…). **Always use these.** |
| `app/` | Feature screens, drawers, modals, forms |
| `app/unibox/` | Unibox thread list / view / filters |
| `auth/` | `login-form.tsx` |
| `leads/` | `lead-ui.tsx` small lead badges/helpers |

The UI hard rules (shared components only, the Attio surface ladder and tag colours, no focus
rings, no entrance animations) are in the root `CLAUDE.md` — follow them.
